# 我的搜索

给 AstrBot 加上方便好记的联网搜索指令。发送 `/搜一搜 关键词`，即可获得网页资料、摘要和来源链接；结果太长时，可以装进一条合并转发消息。

插件使用 [Anysearch](https://anysearch.com/) 搜索服务，基于 [AgIzT/astrbot_plugin_anysearch](https://github.com/AgIzT/astrbot_plugin_anysearch) 改造，使用独立的插件标识和 AI 工具名称。

## 能做什么

- **搜一搜**：查找公开网页资料，结果数量可配置。
- **看网页**：读取公开网页正文，适合摘要不够详细时继续查看。
- **一起搜**：一次搜索最多 5 个关键词，方便比较和收集资料。
- **少刷屏**：选择合并转发、长结果转发或分段文本；超长内容会按输出上限截断并提示。
- **AI 联网**：向 AstrBot 提供搜索、网页提取和批量搜索工具，让支持工具调用的模型按需查询资料。
- **减少重复请求**：短时内存缓存、进行中请求合并和并发限制。

## 安装与开始使用

需要 **AstrBot 4.16 或更高的 4.x 版本**，以及能访问 `https://api.anysearch.com/mcp` 的网络环境。

1. 在 AstrBot 管理面板的插件管理中，选择通过仓库地址安装，填入：

   ```text
   https://github.com/Whereis-Alice/astrbot_plugin_my_search
   ```

2. 打开“我的搜索”的配置。API Key 可先留空尝试匿名访问；遇到额度或授权提示时，在 [Anysearch API Key 页面](https://anysearch.com/console/api-keys) 获取 Key 并填入。匿名访问是否可用、额度与费用均以服务方当前规则为准。
3. 在聊天中发送 `/搜一搜 AstrBot 安装教程`。

本文使用 `/` 作为指令前缀示例。若你的 AstrBot 使用其他唤醒前缀，请替换为实际前缀；指令与参数之间留一个空格。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/搜一搜 AstrBot 安装教程` | 搜索一个关键词或问题 |
| `/看网页 https://docs.astrbot.app/` | 提取网页正文 |
| `/一起搜 AstrBot；NapCat` | 批量搜索，用中文分号分隔 |
| `/搜一搜 帮助` | 查看简要用法；只输入 `/搜一搜` 也可以 |

如果只想记一个指令，还可以使用：

```text
/搜一搜 提取 https://docs.astrbot.app/
/搜一搜 批量 AstrBot；NapCat
/搜一搜 https://docs.astrbot.app/
```

直接给 `/搜一搜` 一个公开 URL，会自动提取该网页。`/我的搜索` 是 `/搜一搜` 的别名；`/我的网页`、`/我的批搜` 分别是另两个指令的别名。

批量搜索支持中文或英文分号、逗号；重复关键词会去重。超过 5 个不同关键词时会提示分批发送，不会悄悄丢弃。如果关键词本身含逗号，可以用 JSON 字符串数组保留完整内容：

```text
/一起搜 ["上海,天气", "北京,天气"]
```

指令返回搜索服务提供的资料，不会额外调用模型生成总结。来源链接按服务返回内容保留；内容被截断时，尾部尚未显示的结果也可能被省略。搜索结果和正文提取的质量、时效、网站覆盖范围由搜索服务决定。

## 如何设置合并转发

打开插件配置，找到“指令结果发送方式”：

| 选项 | 行为 |
| --- | --- |
| 合并转发（默认） | 支持的平台上，指令结果使用合并转发 |
| 长结果转发 | 达到“长结果转发阈值”时才使用合并转发，短结果发文本 |
| 分段文本 | 始终使用文本；长内容按段落或换行分段 |

**合并转发仅支持 OneBot v11（如 NapCat 对接的 `aiocqhttp` 平台）。** 默认群聊转发、私聊文本。如果也想在私聊转发，请开启“私聊也使用合并转发”；实际能否发送取决于协议端。

其他平台自动使用文本。转发发送报错时，会提示并自动改用分段文本；普通文本也无法发送时，需要检查协议端、平台权限和消息长度限制。

转发的每个节点显示名称默认为“我的搜索”，正文按段落分配到多个节点。这些设置只影响本插件的指令结果。**AI 调用工具后的最终回答仍由 AstrBot 和模型决定**，不会因为这里选择了转发就自动转发。

## 配置参考

通常只需调整发送方式和结果数量；其他选项可保持默认。保存后按管理面板提示重载插件。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| API Key | 空 | 可选，填写 Anysearch 提供的 Key |
| 指令结果发送方式 | 合并转发 | 合并转发 / 长结果转发 / 分段文本 |
| 私聊也使用合并转发 | 关闭 | 开启后私聊也按发送方式处理 |
| 长结果转发阈值 | 1000 字符 | 仅“长结果转发”生效，范围 100–10000 |
| 每次搜索的结果数量 | 5 | 范围 1–10；批量搜索的每个关键词均适用 |
| 指令结果输出上限 | 6000 字符 | 范围 500–60000，超出时截断并提示 |
| 每条文本或转发节点的长度上限 | 1000 字符 | 范围 300–3000；文本分段标注顺序 |
| 合并转发节点的显示名称 | 我的搜索 | 最长 32 字符 |
| 注册 AI 联网工具 | 开启 | 关闭后搜索指令仍可使用 |
| AI 工具返回内容上限 | 12000 字符 | 范围 500–60000，限制模型收到的资料长度 |
| 单次网络请求超时 | 30 秒 | 范围 5–120；临时 502/503/504 错误仅重试一次 |
| 相同请求的缓存时间 | 60 秒 | 范围 0–3600，0 关闭；查即时变化可设为 0 |
| 最大并发网络请求数 | 3 | 范围 1–10；不同请求最多排队 32 项 |

缓存只保存成功结果，最多 64 项，单项超过 128 KiB 不缓存；仅存在于内存中，卸载或重载后清空。失败请求不缓存。

## AI 自动搜索

在 AstrBot 中为当前会话启用本插件工具，并使用支持工具调用的模型。然后可以说：“帮我查一下 AstrBot 的最新文档，并给出来源。”是否调用、调用几次以及最终如何回答，由模型和 AstrBot 的工具设置决定。

| 工具名称 | 功能 |
| --- | --- |
| `my_search_search` | 搜索一个问题，可指定 1–10 条结果 |
| `my_search_extract` | 提取公开网页正文 |
| `my_search_batch` | 搜索 1–5 个关键词，每项可使用同一个结果数量 |

这些名称、插件标识 `astrbot_plugin_my_search` 和指令均已与原插件区分。可以与原插件同时安装，但启用内容相近的两套 AI 工具时，模型可能自行选择其中一套。原插件配置不会自动迁移，新插件需单独配置。

## 常见问题

**选择了转发，为什么仍然发文本？** 先确认使用 OneBot v11；私聊还需要开启私聊转发。“长结果转发”模式的短结果会发文本。转发失败时也会回退为文本。

**为什么出现额度不足、无效 Key 或超时？** 插件依赖 Anysearch 服务。检查 API Key、账户额度和 AstrBot 网络；超时可适当增加“单次网络请求超时”。额度或鉴权错误不会自动重试。

**为什么网页无法提取？** 需要公开的 http(s) 页面；登录页、反爬网站和服务不支持的网站可能失败。本地、内网、带账号密码或格式错误的 URL 会被拒绝。

**为什么结果不完整？** 服务可能只找到少量结果；也可能触发了插件输出上限。出现截断提示时，可缩小查询范围或提高上限。提取正文时同样适用。

**能保证“最近一天新闻”或按内容类型筛选吗？** 当前接口不提供原插件的 `freshness` / `content_types` 筛选参数。可以在关键词中表达时间或资料类型，或尝试 `site:example.com` 限定站点，但过滤效果取决于搜索服务，不保证严格筛选。

## 数据与来源

关键词和待提取的 URL 会发送至 `https://api.anysearch.com/mcp`；填写的 API Key 仅用于该服务的鉴权。插件不会把搜索记录写入磁盘，也不会在错误日志中打印 Key、服务响应正文或搜索关键词。

网页提取会检查 URL 格式和明显的非公网目标；域名在服务方如何解析、网页跳转到哪里，仍由远端服务处理，本插件不能保证远端抓取的网络边界。搜索结果和网页内容应作为外部资料核对来源。
