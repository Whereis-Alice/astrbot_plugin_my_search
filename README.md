# 我的搜索

给 AstrBot 加上方便好记的联网搜索指令。发送 `/搜一搜 关键词`，即可获得网页资料、摘要和来源链接；OneBot 可以合并转发，QQ 官方机器人可以使用 Markdown 排版和可点击的来源链接。

插件使用 [Anysearch](https://anysearch.com/) 搜索服务，基于 [AgIzT/astrbot_plugin_anysearch](https://github.com/AgIzT/astrbot_plugin_anysearch) 改造，使用独立的插件标识和 AI 工具名称。

## 能做什么

- **搜一搜**：查找公开网页资料，结果数量可配置。
- **看网页**：读取公开网页正文，适合摘要不够详细时继续查看。
- **一起搜**：一次搜索最多 5 个关键词，方便比较和收集资料。
- **少刷屏**：选择合并转发、长结果转发或分段文本；超长内容会按输出上限截断并提示。
- **QQ 官 bot 排版**：群聊、单聊和频道支持 Markdown 标题、列表和来源链接，可单独关闭排版或隐藏链接。
- **AI 联网**：向 AstrBot 提供搜索、网页提取和批量搜索工具，让支持工具调用的模型按需查询资料。
- **减少重复请求**：短时内存缓存、进行中请求合并和并发限制。

## 安装与开始使用

需要 **AstrBot 4.16 或更高的 4.x 版本**，以及能访问 `https://api.anysearch.com/mcp` 的网络环境。

1. 在 AstrBot 管理面板的插件管理中，选择通过仓库地址安装，填入：

   ```text
   https://github.com/Whereis-Alice/astrbot_plugin_my_search
   ```

2. 打开“我的搜索”的配置。API Key 可先留空尝试匿名访问；遇到额度或授权提示时，在 [Anysearch API Key 页面](https://anysearch.com/console/api-keys) 获取 Key 并填入。匿名访问是否可用、额度与费用均以服务方当前规则为准。
3. 在聊天中发送 `/搜一搜 AstrBot 安装教程`。

本文使用 `/` 作为指令前缀示例。若你的 AstrBot 使用其他唤醒前缀，请替换为实际前缀；指令与参数之间留一个空格。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/搜一搜 AstrBot 安装教程` | 搜索一个关键词或问题 |
| `/搜一搜 搜索 https://tieba.baidu.com/p/帖子编号` | 只搜索链接相关资料，不提取网页正文 |
| `/看网页 https://docs.astrbot.app/` | 提取网页正文 |
| `/一起搜 AstrBot；NapCat` | 批量搜索，用中文分号分隔 |
| `/搜一搜 帮助` | 查看简要用法；只输入 `/搜一搜` 也可以 |

如果只想记一个指令，还可以使用：

```text
/搜一搜 提取 https://docs.astrbot.app/
/搜一搜 批量 AstrBot；NapCat
/搜一搜 https://docs.astrbot.app/
```

直接给 `/搜一搜` 一个公开 URL，会自动提取该网页，与 `/看网页 URL` 相同。如果只想搜索链接相关资料，请使用 `/搜一搜 搜索 URL`。这会调用搜索接口，结果是否包含该链接取决于搜索服务，不保证获得该网页正文。`/我的搜索` 是 `/搜一搜` 的别名；`/我的网页`、`/我的批搜` 分别是另两个指令的别名。

批量搜索支持中文或英文分号、逗号；重复关键词会去重。超过 5 个不同关键词时会提示分批发送，不会悄悄丢弃。如果关键词本身含逗号，可以用 JSON 字符串数组保留完整内容：

```text
/一起搜 ["上海,天气", "北京,天气"]
```

指令返回搜索服务提供的资料，不会额外调用模型生成总结。来源链接按服务返回内容保留；内容被截断时，尾部尚未显示的结果也可能被省略。搜索结果和正文提取的质量、时效、网站覆盖范围由搜索服务决定。

## 如何设置合并转发

使用 OneBot v11 时，打开插件配置，找到“OneBot 指令结果发送方式”：

| 选项 | 行为 |
| --- | --- |
| 合并转发（默认） | 支持的平台上，指令结果使用合并转发 |
| 长结果转发 | 达到“长结果转发阈值”时才使用合并转发，短结果发文本 |
| 分段文本 | 始终使用文本；长内容按段落或换行分段 |

**合并转发仅支持 OneBot v11（如 NapCat 对接的 `aiocqhttp` 平台）。** 默认群聊转发、私聊文本。如果也想在私聊转发，请开启“私聊也使用合并转发”；实际能否发送取决于协议端。

QQ 官 bot 使用下一节的独立设置；其余平台自动使用文本。转发发送报错时，会提示并自动改用分段文本；普通文本也无法发送时，需要检查协议端、平台权限和消息长度限制。

转发的每个节点显示名称默认为“我的搜索”，正文按段落分配到多个节点。这些设置只影响本插件的指令结果。**AI 调用工具后的最终回答仍由 AstrBot 和模型决定**，不会因为这里选择了转发就自动转发。

## QQ 官方机器人怎么用

先在 AstrBot 中配置好 QQ 官方机器人平台，再安装本插件。插件支持 `qq_official` 和 `qq_official_webhook`；Webhook 接入需要你的 AstrBot 版本本身提供该适配器。插件复用已配置的机器人，不需要额外填写 QQ AppID 或 AppSecret。

指令与其他平台相同。群聊中先 @机器人，再按 AstrBot 的实际唤醒前缀发送 `/搜一搜 关键词`、`/看网页 URL` 或 `/一起搜 关键词一；关键词二`。默认启用“QQ 官 bot 使用 Markdown 排版”和“QQ 官 bot 显示来源链接”。搜索结果的排版示例：

```markdown
## 我的搜索 · 搜索结果

## 1. AstrBot 文档
来源：[查看来源](https://docs.astrbot.app/)

这里显示搜索服务返回的资料。
```

原始来源 URL 和常见的 Markdown 链接会整理为可点击的链接；较长 URL 会整体移到下一条消息，无法容纳时会明确提示省略。网页中的图片整理为图片链接，不直接发送图片。代码块和复杂排版按普通文字整理，方便在 QQ 中阅读。

根据 [QQ 官方 Markdown 文档](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/type/markdown.html)，**群聊和单聊自定义 Markdown 已于 2026 年 4 月 23 日开放，无需申请模板**；频道 Markdown 仍需开通相应权限。链接能否发送、客户端如何跳转，仍由 QQ 平台规则决定。

- 想始终发普通文本：关闭“QQ 官 bot 使用 Markdown 排版”。
- 不希望发送 URL：关闭“QQ 官 bot 显示来源链接”，链接位置会显示“链接已隐藏”。
- 想少发几条：调整“QQ 官 bot 每次结果最多回复几条”，默认 3 条。每条沿用长度上限，最多按 2000 字符处理；超过条数或总输出上限会截断并提示。

QQ 的被动回复额度目前为单聊每条用户消息最多 4 次、群聊最多 5 次，因此插件会按场景限制条数。其他插件的回复也可能占用额度；规则详见 [QQ 消息收发文档](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)。

平台明确拒绝 Markdown 时，当前及后续消息会改用普通文本；明确返回“不允许发送 URL”时，会隐藏当前及后续消息的链接。已发出的部分不会重新发送。超时、额度不足和内容审核拒绝等错误会报告发送失败。

这些设置只影响本插件的成功指令结果。帮助和错误提示使用简短文字；AI 工具调用后的最终回复仍由 AstrBot 和模型处理。

## 配置参考

通常只需调整发送方式和结果数量；其他选项可保持默认。保存后按管理面板提示重载插件。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| API Key | 空 | 可选，填写 Anysearch 提供的 Key |
| OneBot 指令结果发送方式 | 合并转发 | 合并转发 / 长结果转发 / 分段文本 |
| 私聊也使用合并转发 | 关闭 | 仅对 OneBot v11 生效 |
| QQ 官 bot 使用 Markdown 排版 | 开启 | 支持标题、列表和来源链接；关闭后发文本 |
| QQ 官 bot 显示来源链接 | 开启 | 关闭后隐藏 http(s) 链接；点击跳转受 QQ 规则限制 |
| QQ 官 bot 每次结果最多回复几条 | 3 | 范围 1–5；单聊最多 4 条，群聊最多 5 条，超出截断 |
| 长结果转发阈值 | 1000 字符 | 仅“长结果转发”生效，范围 100–10000 |
| 每次搜索的结果数量 | 5 | 范围 1–10；批量搜索的每个关键词均适用 |
| 指令结果输出上限 | 6000 字符 | 范围 500–60000，超出时截断并提示 |
| 每条文本、Markdown 或转发节点的长度上限 | 1000 字符 | 范围 300–3000；QQ 官 bot 最多按 2000 字符处理 |
| 合并转发节点的显示名称 | 我的搜索 | 最长 32 字符 |
| 注册 AI 联网工具 | 开启 | 关闭后搜索指令仍可使用 |
| AI 工具返回内容上限 | 12000 字符 | 范围 500–60000，限制模型收到的资料长度 |
| 单次网络请求超时 | 30 秒 | 范围 5–120；临时 502/503/504 错误仅重试一次 |
| 相同请求的缓存时间 | 60 秒 | 范围 0–3600，0 关闭；查即时变化可设为 0 |
| 最大并发网络请求数 | 3 | 范围 1–10；不同请求最多排队 32 项 |

缓存只保存成功结果，最多 64 项，单项超过 128 KiB 不缓存；仅存在于内存中，卸载或重载后清空。失败请求不缓存。

## AI 自动搜索

在 AstrBot 中为当前会话启用本插件工具，并使用支持工具调用的模型。然后可以说：“帮我查一下 AstrBot 的最新文档，并给出来源。”是否调用、调用几次以及最终如何回答，由模型和 AstrBot 的工具设置决定。

| 工具名称 | 功能 |
| --- | --- |
| `my_search_search` | 搜索一个问题，可指定 1–10 条结果 |
| `my_search_extract` | 提取公开网页正文 |
| `my_search_batch` | 搜索 1–5 个关键词，每项可使用同一个结果数量 |

这些名称、插件标识 `astrbot_plugin_my_search` 和指令均已与原插件区分。可以与原插件同时安装，但启用内容相近的两套 AI 工具时，模型可能自行选择其中一套。原插件配置不会自动迁移，新插件需单独配置。

## 常见问题

**选择了转发，为什么仍然发文本？** 先确认使用 OneBot v11；私聊还需要开启私聊转发。“长结果转发”模式的短结果会发文本。转发失败时也会回退为文本。

**为什么出现额度不足、无效 Key 或超时？** 插件依赖 Anysearch 服务。检查 API Key、账户额度和 AstrBot 网络；超时可适当增加“单次网络请求超时”。额度或鉴权错误不会自动重试。

**普通搜索正常，为什么贴吧等网页无法提取？** 搜索和网页正文提取是两项不同的能力。服务能搜索到摘要，不代表能读取完整网页；登录页、访问限制、反爬和服务不支持的网站可能导致提取失败。直接给 `/搜一搜` 一个 URL 也会走提取接口，因此与 `/看网页` 返回相同错误是正常的。可改用 `/搜一搜 搜索 URL` 查相关资料，插件不会把搜索摘要冒充网页正文。

**错误提示里的 `extract_failed` 是什么意思？** 这是搜索服务返回的错误码，表示网页提取失败。v1.0.1 起会显示中文解释、简短的服务说明和请求编号（服务提供时），并在 AstrBot 日志记录同样的脱敏诊断信息。有些服务错误只说明“无法提取此 URL”，没有进一步原因；插件会保留这个事实，不会把它一概归为额度不足。本地、内网、带账号密码或格式错误的 URL 仍会在请求前被拒绝。

**收到合并转发了，为什么后台没有常规发送记录？** 插件直接调用平台发送接口，可能不会出现 AstrBot 的 `respond.stage` 常规日志。v1.0.2 起会分别记录请求完成和发送结果。例如：

```text
我的搜索：网页提取完成，平台=aiocqhttp，结果长度=1234字符。
我的搜索：合并转发发送成功，平台=aiocqhttp，节点=2，正文=1234字符，已截断=否。
```

文本发送、转发回退和发送失败也有对应记录。插件的成功日志不包含正文或完整 URL。“发送成功”表示平台发送接口未抛出异常，不表示对方已经阅读；如果多条文本只发出部分，会记录实际已发送条数。

**QQ 官 bot 的发送能在后台看到吗？** v1.1.0 起会记录实际成功的 Markdown 条数、文本条数、链接显示状态和截断状态。只有 QQ 接口返回消息 ID 后，才记作发送成功；降级和部分失败也有日志。它表示平台接口已接受消息，不保证对方已阅读。

**为什么结果不完整？** 服务可能只找到少量结果；也可能触发了插件输出上限。出现截断提示时，可缩小查询范围或提高上限。提取正文时同样适用。

**能保证“最近一天新闻”或按内容类型筛选吗？** 当前接口不提供原插件的 `freshness` / `content_types` 筛选参数。可以在关键词中表达时间或资料类型，或尝试 `site:example.com` 限定站点，但过滤效果取决于搜索服务，不保证严格筛选。

## 数据与来源

关键词和待提取的 URL 会发送至 `https://api.anysearch.com/mcp`；填写的 API Key 仅用于该服务的鉴权。插件不会把搜索关键词和网页正文写入磁盘，短时缓存仅保存在内存中。成功日志记录调用类型、平台、长度和发送数量；错误日志记录调用类型、错误码、简短服务说明和请求编号。插件的日志不会打印完整响应，已知 API Key、请求参数、鉴权字段和 URL 会从错误说明中隐藏。

网页提取会检查 URL 格式和明显的非公网目标；域名在服务方如何解析、网页跳转到哪里，仍由远端服务处理，本插件不能保证远端抓取的网络边界。搜索结果和网页内容应作为外部资料核对来源。
